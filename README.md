# 戴师行旅图

THE JOURNEY OF MR. DAI · 2603班敬赠戴能斌老师

一部移动端优先、可以移卷探索、进入五处画境、亲手题字盖印并导出纪念图的静态数字作品。所有运行资源随项目提供，无账户、付费 API、外部字体 CDN 或服务端依赖。

## 运行与构建

需要 Node.js 20 或更新版本，建议 Node.js 22。项目没有第三方运行依赖。

```sh
npm ci
npm test
npm run build
```

构建后将 `dist/` 里的全部文件部署到任意静态主机。直接双击本地 HTML 可能因为浏览器的 ES Modules 安全策略无法运行；请通过 HTTP 服务打开，例如：

```sh
python3 -m http.server 8080 --directory dist
```

然后打开 `http://localhost:8080`。使用手机时，可在同一局域网打开运行服务器的设备地址。成品的实际运行不需要 Node.js。

## GitHub Pages

将源码包解压后的内容上传到一个 GitHub 仓库的根目录，包含 `.github/workflows/pages.yml`，默认分支使用 `main`。进入仓库 **Settings → Pages → Source**，选择 **GitHub Actions**。推送后工作流会自动检查、构建并部署。

所有资源地址使用相对路径，因此同时适用于用户主页、项目子路径和其他静态主机。也可直接部署随包附带的 `dist/`，无需构建。本作品已上传至 GitHub，使用仓库自带的 GitHub Actions 工作流部署至 Pages。

## 游览

* **展卷**：轻触“展卷入画”。卷面支持手指拖动、鼠标拖动、滚轮以及左右方向键。下方五处题签可直接移卷；画中门庭可进入场景。
* **归卷**：左上角“归卷”、Escape 键，或在场景空白处向右划。返回时保留原长卷位置。
* **寻物**：各场景内的“寻物”展开文字操作入口，无需精确点中物件。触摸目标至少 48px。
* **竹窗初见**：点击或向上拖动竹帘；翻看书案小笺；先生点头；触鸟有反馈；点击砚台或按住砚台让墨色洇开。
* **偷来的两分钟**：点击计时盘、左右拖动它，或拖动下方刻度。刻度接近末端时先生放下书、门打开、学生走向门外。刻度只是象征，不是学校的真实作息时间。
* **一身兼数艺**：翻曲谱、拨弦、拖动旧物、触碰庭外。开启声音后可听原创旋律。
* **庭前有风**：点球，拖动风筝或牵风刻度，探索竹叶和石阶。点击“一起接球”抛球；球接近先生时再点击即可接住。无分数排行榜、失败惩罚或强制任务。
* **山水有期**：听溪、看云、歇脚三条想象小路均可探索；亭中卷轴进入题跋。卷末题跋也可从长卷下方直接进入，不必完成全部章节。
* **题跋**：用手指、鼠标或笔书写；可撤销、清纸、输入最多 64 字短笺。按住朱印约 0.85 秒落款，键盘可按住空格或 Enter。落印后保存为 **1080×1440 PNG**。提供图片下载、系统分享（浏览器支持时）和长按图片保存。

## 本地数据与声音

探索记录、题字、留言和落印状态通过 `LocalStorage` 保存在当前浏览器，键为 `dai-journey-v1`。没有上传、多人留言同步、统计分析或跨设备同步。私密模式、清理浏览器数据或更换设备会影响留存。若存储被浏览器限制，本次绘写与导出仍可进行。

声音默认关闭，每次打开作品都需要主动开启“听风”。本项目通过 Web Audio API 原创合成风声、鸟鸣、纸声、琴弦风格音色和落印声，不使用商业录音、教师嗓音或音色克隆。声音可以随时关闭，切到后台时暂停。

“重新游览”从卷首重新观看，保留题字与已探索记录；“清纸”清除当前笔迹和印记，留言可另行编辑。

## 画面与性能

原创青绿山水底画、透明学堂建筑及人物资源与程序绘制前景组合。画中人物是艺术化形象，并非戴老师真实肖像。建筑、题跋与山间未来想象不作为真实人生事实。真实叙事仅采用本项目提供的温柔负责、不拖堂、提前两分钟下课、曾练声乐并选择体育等信息。

Canvas 2D 分层渲染；长卷前景按可见章节生成缓存，最多保留三个；进入场景才加载建筑资源，最多保留两个场景缓存。高 DPI 渲染上限 1.75；轻绘模式 1.25、约 24 FPS，仍保留所有互动。检测到较小设备内存时默认启用轻绘。支持横竖屏、`100dvh`、安全区域及输入区独立滚动。后台暂停绘制；支持 `prefers-reduced-motion`，减少环境循环而保留小游戏与关键动作。

素材无法载入时使用本地矢量画境继续游览；没有全屏加载阻塞。由于不同手机浏览器的下载与 Web Share 支持不一致，导出预览始终保留长按保存入口。

## 已执行检查与验证边界

已执行 `npm test`（7项）和 `npm run build`。事件检查实际加载应用模块，覆盖五章探访和返回、移卷误触判定、计时开门、接球、书写撤销、长按不足与成功盖印、图片生成流程及本地留存。另通过原生 Canvas 2D 实际渲染了五处场景、长卷和 1080×1440 纪念图，检查了画面合成。

事件测试使用无浏览器的 DOM/Canvas 事件夹具。它不等同于 Android 真机测试。本次环境未提供受支持的浏览器检查通道，因此没有声称完成手机真机、浏览器截图、实际下载或 60 FPS 性能实测。正式向全班分享前，建议在实际使用的 Android 浏览器中走一遍“展卷→任意场景→归卷→题字→长按印章→保存”。GitHub Pages 的大陆网络可达性取决于网络，静态目录可直接迁移至其他主机。

## 文件结构

```text
index.html                     应用结构与可访问入口
src/app.js                     手势、状态转换、输入、声音控制与导出
src/art.js                     原创绘画图形与实时对象
src/state.js                   章节、状态与安全本地恢复
src/audio.js                   原创合成环境音
src/style.css                  纸绢界面、手机与横屏布局
assets/                        本地画面、字体与朱印
scripts/build.mjs              零依赖静态构建
tests/                         状态及完整操作路径检查
.github/workflows/pages.yml    GitHub Pages 自动部署
dist/                          已构建、可迁移静态成品
ASSETS.md                      素材来源与生成说明
FONT-LICENSE.txt               字体许可
```

初次进入、展卷、长卷、场景、题跋和导出为明确模式；场景转场可被新的导航操作替换，避免重复进入产生错乱。场景监听集中管理，不随探访次数叠加。
